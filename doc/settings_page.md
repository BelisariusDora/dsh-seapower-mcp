# 游戏内 Settings 页面

归属：第四层人机交互。参见 [四层文档索引](README.md)。

2026-11-06。控制台第三个标签为 Settings / 设置，沿用现有窗口的打开、关闭、拖动、缩放和最小化行为。

## 可修改的选项

| 选项 | setting.ini | 生效时机 |
|---|---|---|
| 菜单打开 / 关闭键 | [AgentInspector] ToggleKey | 保存后立即更新实际轮询；默认 N |
| 界面语言：跟随游戏、English、简体中文 | [AgentInspector] Language（空 / en / zh） | 保存后切换现有本地化表与 Settings 标签 |
| 精简 MCP 回复 | [MCP] CompactReplies | 下一次支持字段投影的 MCP 查询 |
| 仅使用主 Agent 操作（默认关闭） | [Tickets] MainAgentOnly | 保存后新建的工单；已有工单保持原执行方式 |
| 截图保存原始分辨率 | [AgentInspector] ShotSaveFull | 下一次截图保存；交给模型的图像仍使用缩小版本 |

第一次读取缺省值沿用现有逻辑：语言跟随游戏、精简回复关闭、原图保存关闭。升级不会用默认值覆盖已有配置。点击选项只修改草稿；“保存”写入设置，“放弃修改 / 重新读取”丢弃草稿并读取当前文件。切换标签保留尚未保存的草稿；游戏退出不保存草稿。设置属于玩家偏好，会跨对局保留，不是聊天记忆。

窗口较小时，选项按页显示，使用 < / > 翻页，避免依赖游戏视图中未提供模板的 ScrollViewer。布尔项采用与已验证控制台按钮相同的绘制控件，以 [x] / [ ] 显示选择。

仅主 Agent 模式已接入 DSH 与 Codex：仍建单，但由创建该工单的主会话在当前轮次完成接口交互。可能改善执行效果，也可能增加思考耗时。详见 main_agent_mode.md。现有页面的全面本地化仍是后续工作；本页和三个控制台标签均加入中英翻译表，模型回复不作自动翻译。

## 保存与模块

src/PlayerSettings.cs 复用既有 Inspector 配置解析，合并时只更新上述五个键，保留其他键、节、窗口布局和注释。为兼容既有语言和截图读取器，托管键的行内注释改为独立注释行。写入先落同目录临时文件并 flush，再通过文件替换提交；失败时显示原因，保留草稿，原文件不被截断。

src/SettingsWindow.cs 实现草稿、保存/重新读取和小窗口分页；src/ConsoleHost.cs 增加 settings 标签与页面挂载；src/Strings.cs 增加中英标签。仅主 Agent 模式复用工单权限、调用账本与既有业务 API；异常通知轮次仍禁止所有工具。

现有控制台入口 POST /console/show {"page":"settings"} 可打开页面；GET /console/state 的 settings 字段提供安装状态、草稿、页码、未保存标记与错误，供界面验收使用。没有新增远程修改设置的业务工具。

正常使用 build.ps1 -Deploy，需退出游戏后加载新 DLL。构建部署保留既有 setting.ini 和 persona.md；本文同步到 <MOD_ROOT>/harness/SETTINGS.md。

离线检查对真实构建 DLL 验证原子保存失败不损坏原文件、未知配置和注释保留、默认/别名解析、首次安装、重复托管键处理，以及 Inspector 保存和截图读取兼容。验证脚本 test/settings_preferences.ps1 需要现有 PowerShell 7 环境，参数为测试目录、构建 DLL、游戏 Newtonsoft.Json.dll；不修改系统的强名称或安全设置。

### 菜单键绑定补充

点击“菜单打开 / 关闭键”后按下新键，支持单个字母、数字或 F1–F12。Esc 或再次点击录制按钮取消，切换页面、关闭或最小化菜单也会结束录制。录制只改草稿，保存后实际热键才改变；保存前原键继续有效，录制当帧不会触发菜单开关。输入消息时仍由输入框优先，不因菜单绑定误开关。

沿用 [AgentInspector] ToggleKey，不新增另一套冲突配置。缺失或不支持的键回退到 N。该设置只绑定本模组菜单，不重写游戏原有快捷键；应选择空闲键。后台轮询缓存已生效键，不逐帧读写配置文件。保存及重新读取时刷新缓存。

新增热键的实际录制、Esc 取消、新键开关、旧键失效和消息输入保护须做游戏内验证；44 项设置离线检查和 93 项 Python 回归已通过。

# 语言文件与本地化

本模组沿用游戏的语言目录形状，不另设一套 JSON 翻译配置：

```text
<MOD_ROOT>/language_en/ui.ini
<MOD_ROOT>/language_cn/ui.ini
```

源码默认表位于 deployment/assets 下的同名目录。当前支持 English 和简体中文，不声称新建任意语言文件夹即可自动增加 Settings 语言选项。

## 语言选择

Settings 的“跟随游戏”读取游戏 usersettings.ini 的语言；明确选择 English/简体中文时由模组 [AgentInspector] Language 覆盖。解析和选择仍由现有 C# Strings 完成，已解析的 uiLanguage 通过 /comms/state 交给调度器；Python 不再独立猜测操作系统或用户语言。游戏语言不可用时保留现有系统/英文回退。

## 文件格式与编辑

```ini
[AgentInspector]
tickets.title=任务工单
tickets.expand=显示详情
tickets.destroy=销毁
tickets.previous=上一页
tickets.next=下一页
```

UTF-8，允许 BOM；按第一个等号拆成 Key=Value，节名可省略，分号或井号开头为注释，重复键最后一个生效。键名保持不变，修改等号后的文字；值中的等号保留，行末不使用行内注释。保留格式占位符：C# 界面使用 {0} 等，工单中已有计数模板保留 %d 等；不要翻译 API 名称、状态代码和 JSON 字段名。

重新选择语言或关闭后重开通联页面以加载修改；后端工单视图会在资源文件时间戳变化后重新生成，不修改原账本。当前语言缺少的后端键回退英文表，再回退键名；界面保留 Strings 现有内置及英文回退。

## 覆盖与边界

每种语言当前提供 125 个资源项：既有检查器、控制台和 Settings 文本，以及工单按钮和 62 项工单呈现文本。工单状态、已记录命令/读取统计、Watch 摘要、详情固定标题均从资源读取。尚未接入 Strings 的其他通联固定文本仍是后续范围，不能把本次工单补全写成整个界面已完成翻译。

任务标题、Agent 回复、受阻原因、单位名、原始 API 参数、回执和错误代码保持原文。这些是用户或执行者内容，不进行字符串替换，也不调用模型翻译。英文界面下出现中文 Agent 原始回报属于预期，不是漏翻译。

build.ps1 -Deploy 只补现有 ui.ini 缺失的键，保留用户已有翻译、注释和未知键；重复运行不继续追加相同键。新发布包从源码默认资源构建，不能带入用户临时验收文本或个人语言选择。
